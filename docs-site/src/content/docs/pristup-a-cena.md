Ve spuštění je VISIBLE7 v pilotním provozu a všechny funkce jsou odemčené. Níže je popsaný model, který začne platit se zapnutím ceníku. Aktuální ceny jsou vždy na [visible7.io/cenik](https://visible7.io/cenik).
:::

## Úrovně přístupu

| | Zdarma | Zkušební přístup | Placený přístup |
|---|---|---|---|
| Test nápadu | ✓ | ✓ | ✓ |
| Brány 1–2 a osvědčení za ně | ✓ | ✓ | ✓ |
| Rentgen trhu (ve vašem ChatGPT / Claude) | ✓ | ✓ | ✓ |
| Brány 3–7 a videa | – | ✓ | ✓ |
| Velikost trhu (TAM / SAM / SOM) | – | – | ✓ |
| Export byznys case do Excelu | – | – | ✓ |
| Osvědčení za brány 3–7, Specialista, Gold | – | – | ✓ |
| Pitch na A4 | – | – | ✓ |
| AI za den | 5 | 5 | 20 |
| Aktivní projekty | 1 | 1 | 5 |

**Zkušební přístup** (3 dny) dostanete jednou za vyplnění kvízu „Jaký jsi typ začínajícího podnikatele?“.

## Cena

**Členství na 6 měsíců: 2 990 Kč vč. DPH** jednorázově, nic se samo neobnovuje. Je to startovací cena pro prvních 50 členů, poté 5 990 Kč. Konzultace se seniorními poradci se platí zvlášť.

## Jak funguje platba

1. Zaplatíte přes **SimpleShop**.
2. SimpleShop po zaplacení oznámí VISIBLE7 nákup (e-mail, produkt, doklad).
3. Pokud e-mail patří k vašemu účtu, přístup se zapne hned. Pokud ještě nemáte účet, nákup počká a zapne se při registraci se stejným e-mailem.
4. Pokud už placený přístup máte, nové dny se přičtou k těm zbývajícím.
